# VOLLEY REF 3.0

Mobilná aplikácia pre volejbalového rozhodcu.

## Plánované funkcie
- Fotografovanie lístkov R-5 pre družstvá A/B
- Rozpoznanie postavenia I–VI
- Fotografovanie oficiálneho zápisu a rozpoznanie súpisiek, kapitána a libera
- Kontrola predvyplnených údajov pred potvrdením
- Zachovanie funkcií zápasu z verzie 2.9

## Architektúra
GitHub Pages hostuje iba verejné rozhranie. OpenAI API sa volá výhradne cez zabezpečený backend s kľúčom v serverovom prostredí. **Nikdy nevkladať API kľúč do HTML, JavaScriptu ani GitHub repozitára.**

## Stav
Repozitár pripravený. Nasadenie pôvodného HTML rozhrania a serverovej AI integrácie ešte nie je dokončené.
